# Python Coding Standards

## Naming
- Use descriptive snake_case names for functions and variables.
- Use PascalCase for class names.
- Use uppercase names for constants.

## Functions
- Keep functions focused on one responsibility.
- Use descriptive parameter names.
- Add docstrings to explain non-obvious behavior.

## Error Handling
- Handle expected exceptions explicitly.
- Avoid silently swallowing exceptions.
- Return clear, actionable error messages.

## Code Quality
- Prefer readable code over unnecessarily complex solutions.
- Avoid duplicating logic when a reusable function is appropriate.
- Add tests for important behavior and edge cases.
